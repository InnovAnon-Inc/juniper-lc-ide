Flask Server Integration (Port 5013)

To host this visual lambda calculus environment locally or on a server using Python Flask on port 5013: 

from flask import Flask, render_template_string

app = Flask(__name__)

# Save this HTML file as index.html in the same directory or render directly:
@app.route('/')
def home():
    with open('index.html', 'r', encoding='utf-8') as f:
        return f.read()

if __name__ == '__main__':
    print("🚀 Lambda IDE running on http://127.0.0.1:5013")
    app.run(host='0.0.0.0', port=5013, debug=True)
